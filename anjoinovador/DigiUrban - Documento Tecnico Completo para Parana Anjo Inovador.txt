1. VISÃO GERAL DA SOLUÇÃO
================================================================================

O DigiUrban é uma plataforma GovTech SaaS de gestão pública municipal, desenvolvida
para transformar digitalmente prefeituras de pequeno e médio porte que ainda operam
com processos manuais, papelada, ligações telefônicas e sistemas desconectados.

A solução é composta por um ecossistema integrado de 4 serviços principais e 3
serviços auxiliares especializados, todos orquestrados em arquitetura de
microserviços com Docker Compose:

  - Backend REST API (Express 5 + TypeScript + PostgreSQL/Prisma)
  - Frontend Web PWA (Next.js 14 + React 18)
  - Servidor de Mensagens e Chatbot (Socket.IO + FlowEngine + IA)
  - Servidor SMTP Municipal (envio/recebimento de email institucional)
  - Serviço de IA Local (llama.cpp + Qwen 1.7B — sem envio de dados para nuvem)
  - Motor de Processos (BullMQ + workflows automáticos)
  - Módulo de Preços Públicos (OpenSearch + scraping de fontes governamentais)

A plataforma centraliza em um único ambiente:
  - Abertura e acompanhamento de protocolos digitais
  - Portal do cidadão com autenticação e acompanhamento de serviços
  - Gestão de secretarias municipais (saúde, educação, assistência social e demais)
  - Chatbot conversacional com IA para atendimento 24/7
  - Gestão documental com assinatura digital
  - Email corporativo institucional
  - Analytics e KPIs de desempenho administrativo
  - Notificações em tempo real por múltiplos canais

2. PROBLEMA RESOLVIDO E JUSTIFICATIVA
================================================================================

A realidade das prefeituras brasileiras de pequeno e médio porte é marcada por:

  COMUNICAÇÃO:
  - Atendimento ao cidadão via telefone ou balcão presencial
  - Sem canais digitais unificados de solicitação
  - Informações perdidas em cadernos ou planilhas
  - Cidadão sem como rastrear sua solicitação

  GESTÃO INTERNA:
  - Protocolos em papel sem rastreabilidade
  - Ausência de indicadores de desempenho
  - Falta de controle de SLA e prazos
  - Departamentos operando em silos sem integração

  SAÚDE E SERVIÇOS:
  - Agendamentos médicos ainda manuais
  - Farmácia sem controle informatizado de estoque
  - TFD (Tratamento Fora do Domicílio) sem sistema de gestão
  - Prontuários e registros em papel

  DOCUMENTAÇÃO:
  - Documentos sem assinatura digital
  - Arquivamento físico sem busca eficiente
  - Templates sem padronização

  TRANSPARÊNCIA:
  - Ausência de dados consolidados para o gestor
  - Sem dashboards de acompanhamento
  - Dificuldade de prestar contas com dados

O DigiUrban resolve todos esses problemas com uma plataforma única, acessível
por navegador e mobile, sem necessidade de instalação, integrada entre
departamentos e com custo compatível com a realidade municipal.

4. STATUS ATUAL DE DESENVOLVIMENTO — MVP FUNCIONAL
================================================================================

O DigiUrban possui um MVP completo e funcional, não apenas uma ideia ou protótipo
de tela. Trata-se de um sistema real com:

  - Código-fonte completo em TypeScript (backend + frontend + 5 serviços)
  - Banco de dados relacional com 171 modelos de dados estruturados
  - 88 rotas de API implementadas e funcionais
  - 220+ páginas no frontend (App Router Next.js)
  - Sistema de autenticação dupla (servidores públicos + cidadãos)
  - Chatbot com motor de fluxos conversacionais e IA integrada
  - Módulos de saúde, educação e assistência social implementados
  - Assinatura digital de documentos (certificados X.509)
  - Email corporativo municipal completo com DKIM/SPF
  - Sistema de analytics com dashboards por perfil de acesso
  - Infraestrutura Docker Compose pronta para deploy em VPS

O sistema é orquestrado via Docker Compose e possui:
  - Nginx como proxy reverso e balanceador
  - Supervisord para gerenciamento de processos
  - PostgreSQL como banco principal
  - Redis para cache, filas e sessões
  - Container de IA local com llama.cpp (Qwen 1.7B)

EVIDÊNCIAS TÉCNICAS DO MVP:
  - Repositório Git com histórico de commits
  - Prisma migrations com todo o schema de banco de dados
  - Dockerfile multi-stage (backend-builder + frontend-builder + runner)
  - docker-compose.vps.yml para deploy em produção
  - Seeds de dados para configuração inicial
  - Scripts de diagnóstico e type-check

  - Monorepo com serviços independentes
  - REST API com prefixo /api (88 rotas)
  - WebSocket para comunicação em tempo real
  - JWT em cookies HTTP-only (segurança CSRF)
  - Autenticação separada: admin (digiurban_admin_token) e cidadão (digiurban_citizen_token)
  - Roles hierárquicas: USER → COORDINATOR → MANAGER → ADMIN → SUPER_ADMIN + CITIZEN
  - Multi-tenant: suporte a múltiplos municípios (modelo SUPER_ADMIN)

SEGURANÇA:
  - Helmet.js para headers de segurança HTTP
  - bcrypt para hash de senhas
  - JWT com expiração configurável
  - Certificados digitais X.509 para assinatura
  - DKIM/SPF para autenticidade de emails
  - Chaves privadas criptografadas com AES-256-GCM
  - IA local (dados nunca saem do servidor)
  - Adequação à LGPD na arquitetura de dados

6.1 GESTÃO DE PROTOCOLOS E SERVIÇOS DIGITAIS
------------------------------------------------------------------------

O módulo de protocolos é o coração do DigiUrban. Permite que qualquer
solicitação do cidadão seja aberta, tramitada e concluída digitalmente.

FUNCIONALIDADES:
  - Abertura de protocolo via portal do cidadão ou balcão digital
  - Formulário dinâmico configurável por tipo de serviço (formSchema JSON)
  - Atribuição a servidor/departamento responsável
  - Histórico completo de tramitação com timestamps
  - Controle de status: VINCULADO → PROGRESSO → CONCLUIDO/CANCELADO/PENDENCIA
  - Transições de status controladas por role (config matrix)
  - SLA (Service Level Agreement) por tipo de serviço com alertas de vencimento
  - Pendências formais com descrição e prazo
  - Atualizações e interações registradas com histórico
  - Documentos anexos ao protocolo
  - Campos de dados customizados por protocolo
  - Avaliação de satisfação pelo cidadão (rating 0-5, comentário, recomendação)
  - Vinculação cidadão-protocolo com histórico familiar
  - Exportação CSV com UTF-8 BOM (compatível com Excel)
  - Estágios configuráveis de tramitação

CONFIGURAÇÃO DE SERVIÇOS:
  - Catálogo de serviços por secretaria/departamento
  - Wizard de 8 passos para criação de serviços (ServiceFormWizard)
  - Formulário dinâmico com campos customizáveis
  - Workflows de aprovação por tipo de serviço
  - Módulos de secretaria configuráveis por departamento

MODELOS DE DADOS ENVOLVIDOS:
  ServiceSimplified, ProtocolSimplified, ProtocolHistorySimplified,

6.6 CHATBOT INTELIGENTE — DIGIBOT
------------------------------------------------------------------------

O DigiBot é o assistente virtual do DigiUrban, com arquitetura de fluxos
conversacionais e integração com IA local para compreensão de linguagem natural.

ARQUITETURA DO BOT:
  FlowEngine → NodeExecutors → ActionHandlers → DigiUrbanIntegration → Backend API
         ↕
  CitizenAiOrchestrator → CitizenAiClient → digiurban-ai (llama.cpp)

TIPOS DE NÓS CONVERSACIONAIS (9 tipos):
  message   — Envio de mensagem informativa
  question  — Coleta de resposta livre do cidadão
  menu      — Menu de opções clicável
  action    — Execução de ação no sistema (criar protocolo, buscar dados)
  condition — Desvio condicional de fluxo baseado em dados
  form      — Formulário multi-campo em conversa
  upload    — Recebimento de arquivos do cidadão
  location  — Coleta de localização geográfica
  end       — Finalização de fluxo

FLUXOS PRÉ-CONFIGURADOS (9 fluxos com seed automático no boot):
  menu-principal.json        — Menu principal com 8 opções
  solicitar-servico.json     — Abertura de protocolo via chat
  consultar-protocolo.json   — Consulta + histórico + documentos
  meu-perfil.json            — Edição de dados pessoais pelo chat
  documentos.json            — Acesso a documentos
  avaliacao.json             — Avaliação de atendimento
  minha-familia.json         — Gestão de família
  notificacoes.json          — Preferências de notificação
  ajuda.json                 — Ajuda e suporte

FUNCIONALIDADES DO BOT:
  - Motor de estado persistente (FlowStateManager) — retoma onde parou
  - Template engine para respostas dinâmicas com dados do cidadão
  - Validação inteligente de entrada (InputValidator)
  - Integração direta com backend para criar/consultar protocolos
  - Upload de arquivos em conversa (fotos, documentos)
  - Palavras-chave reservadas para navegação (menu, cancelar, voltar)
  - Timeout 15s para chamadas ao backend com retry automático
  - Erros amigáveis em pt-BR com fallback ao menu principal
  - Proteção de conversa bot contra delete/archive acidental
  - Analytics de uso do bot (BotAnalytics)
  - Mensagens e uploads armazenados permanentemente

CANAIS SUPORTADOS:
  - Chat web (interface do portal do cidadão)
  - WebSocket em tempo real (Socket.IO)
  - Preparado para WhatsApp Business API

IA NO BOT:
  O DigiBot usa a CitizenAiOrchestrator para interpretar texto livre do cidadão
  e extrair intenção, dados e respostas fora dos fluxos estruturados. Isso permite
  que o cidadão escreva de forma natural e o bot entenda o que foi solicitado,
  sem precisar seguir menus rígidos.

6.7 INTELIGÊNCIA ARTIFICIAL LOCAL
------------------------------------------------------------------------

O DigiUrban possui um serviço dedicado de IA (digiurban-ai) que roda
completamente on-premise, sem enviar dados dos cidadãos para serviços externos.

TECNOLOGIAS:
  - llama.cpp — Runtime de inferência LLM otimizado para CPU/GPU
  - Qwen 1.7B — Modelo de linguagem leve e eficiente
  - RAG (Retrieval Augmented Generation) — Busca contextual nos dados do município
  - Cache semântico de respostas para redução de custos computacionais
  - Provedor plugável — permite troca de modelo sem alterar a lógica

CASOS DE USO DA IA:
  - Interpretação de texto livre no chatbot
  - Classificação de solicitações
  - Sugestão de tipo de serviço com base na descrição
  - Extração de dados de formulários preenchidos em linguagem natural
  - Análise preditiva de gargalos em protocolos
  - Respostas contextualizadas com dados do município e cidadão

PRIVACIDADE:
  Toda a inferência de IA ocorre no próprio servidor do município.
  Nenhum dado de cidadão ou conversa é enviado para APIs externas como
  OpenAI, Google ou outros. Isso é fundamental para conformidade com LGPD.

  - Múltiplas contas de email por domínio municipal
  - Templates de email para comunicações automáticas
  - Planos de email configuráveis com limites e domínios
  - Estatísticas de email por conta/domínio
  - Composição de emails com editor rico

  Ano 1 (piloto): 1 a 3 municípios validados

11. DIFERENCIAIS COMPETITIVOS
================================================================================

1. IA LOCAL (sem cloud externo)
   Diferente dos concorrentes que usam ChatGPT/OpenAI, o DigiUrban processa
   todas as requisições de IA localmente com llama.cpp + Qwen 1.7B.
   VANTAGEM: Conformidade total com LGPD, dados sensíveis nunca saem do município.

2. PLATAFORMA VERDADEIRAMENTE INTEGRADA
   Um único sistema que cobre: protocolos, chatbot, saúde, educação, social,
   email institucional, documentos digitais, organograma, analytics.
   VANTAGEM: O município não precisa de 10 sistemas diferentes.

3. EMAIL CORPORATIVO PRÓPRIO
   Servidor SMTP completo incluso, com DKIM/SPF e domínio próprio.
   VANTAGEM: Prefeitura tem @cidade.pr.gov.br sem pagar Google Workspace.

4. CHATBOT COM FLUXOS CONFIGURÁVEIS
   O gestor pode criar e editar fluxos de atendimento sem programação.
   VANTAGEM: Adapta-se ao workflow específico de cada município.

5. ASSINATURA DIGITAL NATIVA
   Documentos com validade jurídica assinados automaticamente.
   VANTAGEM: Elimina a necessidade de sistemas externos de assinatura.

6. RECONHECIMENTO FACIAL EDUCACIONAL
   Controle de acesso e presença em escolas com IA de visão computacional.
   VANTAGEM: Funcionalidade raríssima em sistemas municipais.

7. BUSCA DE PREÇOS PÚBLICOS
   Cotação de preços em fontes governamentais (PNCP, ComprasNet, CATMAT).
   VANTAGEM: Suporte a processos de compras e licitações.

8. MULTI-TENANT E ESCALÁVEL
   Um deploy atende múltiplos municípios isolados (SUPER_ADMIN).
   VANTAGEM: Custo de infraestrutura compartilhado, margem crescente.

9. MVP FUNCIONAL COMPLETO
   Não é protótipo — é um sistema real com 88 rotas, 171 models, 220+ páginas.
   VANTAGEM: Demonstração concreta da capacidade de entrega.

10. FUNDADOR COM EXPERIÊNCIA EM PREFEITURA
    O DigiUrban foi desenvolvido por alguém que conhece os problemas
    reais da gestão municipal por dentro.
    VANTAGEM: Produto construído para resolver dores reais, não hipotéticas.
